# Устройство игры

## Что хранится

- Секрет и попытки хранятся строками, чтобы не терялся ноль в начале.
- Раунд хранится объектом: секрет, длина, система счисления и история попыток. Объект объединяет данные одного раунда.
- История — массив записей с попыткой, bulls и cows. Массив сохраняет порядок попыток и позволяет добавлять новые записи в конец.
- Новая запись добавляется через `[...history, entry]`. Создаётся новый массив, прежний не меняется.
- Для проверки повторяющихся цифр используется `Set`: одинаковые значения в нём не повторяются.
- Лучшие результаты хранятся массивом. У каждого указаны попытки, время и настройки. Оставляются лучшие 10, сначала по попыткам, затем по времени. Массив сохраняется в `localStorage`.

## Как считается

**`evaluateGuess`:** сначала считаются цифры на своих местах — bulls. Затем считаются все цифры, которые есть в секрете. Из этого количества вычитаются bulls — получаются cows. Используются `filter` и `includes`.

**`countPossibleSecrets`:** для первой цифры доступны `base` вариантов. Для следующей остаётся на один меньше. Поэтому функция вызывает себя с меньшей длиной и основанием: `base × countPossibleSecrets(length − 1, base − 1)`. При нулевой длине возвращается 1.

Ответ сохраняется в `Map` для выбранной длины и системы счисления. При повторном вызове берётся сохранённый ответ — это мемоизация.

## Сложность

`n` — количество цифр, `b` — размер алфавита системы счисления. Операции с числами и поиск сохранённого ответа считаются O(1) в среднем.

- **`generateSecret` — O(b + n × b).** Создаётся алфавит из b цифр. Затем n раз выбирается цифра и удаляется через `splice`. При удалении сдвигаются до b элементов.
- **`evaluateGuess` — O(n²).** Для каждой из n цифр попытки просматриваются до n цифр секрета.
- **`isValidGuess` — O(b + n × b).** Создаётся алфавит из b цифр. Каждая из n цифр попытки ищется в нём через `includes`. Повторы проверяются через `Set`.
- **`countPossibleSecrets` — O(n), сохранённый ответ — O(1).** На каждом вызове длина уменьшается на 1. Для сохранённого ответа повторный расчёт не нужен.

## Организация кода — Clean Code

- У каждой функции своя задача: [generateSecret.ts](src/generateSecret.ts) создаёт секрет, [isValidGuess.ts](src/isValidGuess.ts) проверяет попытку, [evaluateGuess.ts](src/evaluateGuess.ts) считает bulls и cows.
- Общая проверка символов находится в [createDigitValidator.ts](src/createDigitValidator.ts). Используется и при вводе, и при проверке попытки, чтобы не дублировать код.
- [submitGuess.ts](src/submitGuess.ts) сразу возвращает прежний раунд для неверной или повторной попытки. Остальной код обрабатывает только принятую попытку.
